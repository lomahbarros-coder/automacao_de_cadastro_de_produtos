# automacao_de_cadastro_de_produtos

## Sobre o Projeto

Este projeto foi desenvolvido como parte de uma aula da **Hashtag Treinamentos**, onde aprendemos a automatizar o cadastro de produtos utilizando a biblioteca pyautogui.  

Durante a aula, pude escrever o código junto com o professor e aplicar diversas bibliotecas e recursos importantes, como:  

- **pandas**  
- **openpyxl**  
- **pyautogui**  
- **time**  
- Estruturas condicionais (**for** e **if**)  

O objetivo principal foi praticar a automação de tarefas repetitivas e integrar diferentes bibliotecas para manipulação de dados e interação com a interface gráfica.
E claro, dei um toque Aloma Barros :sparkler:


## Como Executar o Projeto

Para visualizar o código funcionando, siga os passos abaixo:

1. **Baixar os arquivos**  
   - Certifique-se de baixar todos os arquivos que estão nesta pasta.

2. **Instalar as dependências**  
   - No terminal, execute o comando abaixo para instalar todas as bibliotecas necessárias:  
  
   - O arquivo `pip install` contém todas as dependências usadas no projeto.

3. **Executar o código**  
   - Após instalar as bibliotecas, basta rodar o arquivo principal:  
     ```bash
     python cadastro_de_produtos_auto.py
     ```

4. **Configuração da tela** ⚠️  
   - Como o projeto utiliza **PyAutoGUI**, o tamanho e a resolução da tela interferem diretamente no funcionamento do código.  
   - Caso os cliques não funcionem corretamente, será necessário ajustar as coordenadas dos pontos de clique no código para a sua tela específica.
