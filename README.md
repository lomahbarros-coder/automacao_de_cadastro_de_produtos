# automacao_de_cadastro_de_produtos

## Sobre o Projeto

Este projeto foi desenvolvido como parte de uma aula da **Hashtag Treinamentos**, onde aprendemos a automatizar o cadastro de produtos utilizando a biblioteca pyautogui.  

Durante a aula, pude escrever o código junto com o professor e aplicar diversas bibliotecas e recursos importantes, como:  

- **pandas**  
- **openpyxl**  
- **pyautogui**  
- **time**  
- Estruturas condicionais (**for** e **if**)  

O objetivo principal foi praticar a automação de tarefas repetitivas e integrar diferentes bibliotecas para manipulação de dados e interação com a interface gráfica.
